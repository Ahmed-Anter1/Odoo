# Installable Odoo Portfolio Addons

Five independent Odoo 18 portfolio modules:

- `portfolio_api_connector`
- `portfolio_sale_guard`
- `portfolio_customer_statement`
- `portfolio_mrp_batch`
- `portfolio_whatsapp_share`

Add this `addons` directory to your Odoo addons path, update the Apps list, then install the required modules.

These modules are educational portfolio implementations written independently. Test them in a development database before use.
